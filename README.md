# React Frontend Development Assignments

A collection of React-based frontend development assignments completed as part of an Advanced Frontend Development coursework.

This repository contains practical React applications developed to demonstrate component-based architecture, props, state management, event handling, API integration, responsive UI development, and reusable components.

---

- External CSS
