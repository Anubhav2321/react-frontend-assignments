# React Frontend Development Assignments

A collection of React-based frontend development assignments completed as part of an Advanced Frontend Development coursework.

This repository contains practical React applications developed to demonstrate component-based architecture, props, state management, event handling, API integration, responsive UI development, and reusable components.

---

## 📚 Assignments

### Assignment 01 — Personal Portfolio

A responsive personal portfolio website developed using React and JSX.

#### Key Features
- Header
- Navigation Bar
- About Me
- Education
- Skills
- Contact Information
- Footer
- Responsive Design
- Reusable React Components
- External CSS

#### Technologies
- React
- JSX
- JavaScript
- HTML
- CSS

📁 Project: `portfolio-website`

---

### Assignment 04 — Weather Dashboard

A weather dashboard application that integrates real-time weather information through the OpenWeatherMap API.

#### Key Features
- Search Weather by City
- Temperature
- Humidity
- Wind Speed
- Weather Icon
- Sunrise & Sunset Information
- Loading Spinner
- API Integration
- Async/Await
- Error Handling

#### Technologies
- React
- JavaScript
- OpenWeatherMap API
- Fetch API
- Async/Await
- useEffect
- CSS

📁 Project: `weather-dashboard`

> **Note:** API credentials are stored locally using environment variables and are not included in this repository.
